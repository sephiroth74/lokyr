## What's new

- **Plugins in Luau**: Lokyr runs plugins written in Luau, each in a sandbox of its own, which reach only what you allowed them. The first time a plugin runs, Lokyr asks you for the capabilities that it declares, as reading the clipboard or opening tabs, and again for those that a new version adds; your answers are kept in `permissions.toml`, beside your config, and a plugin whose permission you take back there stops at once. A plugin that runs too long, takes too much memory or keeps failing is stopped, and Lokyr goes on.
- **Sleip, the plugins' package manager, comes with Lokyr**: `sleip` runs in any Lokyr pane. `sleip add --path <folder>` or `sleip add --git <url> --tag <tag>` installs a plugin, `sleip update` takes its new version, `sleip remove` takes it away, and `sleip list` and `sleip doctor` tell what is installed and whether it is sound. Lokyr loads a plugin as it is installed or updated, without restarting.
- **Writing a plugin**: `sleip new owner/name` makes one that runs, with its test; `sleip check` checks its manifest, its translations and its code's types, `sleip test` runs its tests, and `sleip dev` loads it into Lokyr as you write it, again at each save.

## Fixed

- With `quit-after-last-window-closed` on, the windows you had open come back at the next start.
- A window kept on a display that is no longer there opens on one that is, of a size that fits it.
- A script opened from the Finder runs of its own interpreter, as a Python or a Ruby script, and Lokyr asks before it runs one that you downloaded.
- Lokyr › Make Lokyr the Default Terminal follows another app taking the default while Lokyr runs.
