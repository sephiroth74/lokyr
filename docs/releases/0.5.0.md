## What's new

- **About Lokyr**: Lokyr › About Lokyr shows Lokyr's version and build, its copyright and license, and links to its source code and to the licenses of the software that it includes.
- **Turning a built-in plugin off**: `enabled = false` in a plugin's section of the config, as `[plugins.links]` for ⌘-click on links or `[plugins.core-actions]` for copy, paste and the text's size, turns that plugin off as soon as you save the file, and `true` turns it on again. A plugin's own keys go in its section too: a wrong value is told in the window at its line, and the rest of the config applies.

## Works better

- **Resizing a window**: the text follows the window's edge as you drag it, at the display's rate, 60 or 120 Hz, no longer stretched or held for seconds, and a prompt that the shell draws, as a powerline prompt, no longer flickers as the window resizes.
- VoiceOver follows the cursor when it moves without new output, as with the arrow keys at a shell's prompt.
- When a built-in plugin stops on an error, a notice in the window tells it, and the rest of Lokyr goes on.
