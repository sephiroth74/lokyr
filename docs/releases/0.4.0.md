## What's new

- **VoiceOver**: VoiceOver reads the terminal's screen and follows its cursor as programs write.
- **Emoji & Symbols**: Edit › Emoji & Symbols, ⌃⌘Space, opens macOS's palette of emoji and symbols, and the character you choose goes to the program in the terminal.
- **The weight of macOS's text**: `system-weight = true` under `[font]` in the config draws the text as macOS draws its own, dark text on a light background thinner. It is off by default.
- **A terminal type without a description**: when `term` under `[terminal]` names a type that this Mac has no terminfo description of, which makes programs such as the shell draw their lines wrong, Lokyr tells it in the window, and `lokyr +validate-config` tells it too.

## Works better

- The first window shows a refresh sooner, as it did before 0.3.0.
- Lokyr's log, `~/Library/Logs/Lokyr/lokyr.log`, keeps its last lines when Lokyr quits or stops on an error, and starts a new file once it passes a megabyte during a session, not only as Lokyr starts.

## Fixed

- A path written with escaped spaces, as `My\ File.txt`, is underlined again under ⌘, and a click opens it.
- A full disk, or an error writing the log, no longer ends Lokyr with every shell in its windows.
- When the config has an error, or names a font that is not installed, Lokyr no longer checks for updates against `check = false` under `[updates]`.
- The notices of the licenses, in `Lokyr.app/Contents/Resources/licenses`, list only the software that Lokyr includes.
