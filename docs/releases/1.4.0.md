Commands as blocks that you can select, copy and run again, scrolling that follows your fingers pixel by pixel, and controls that look like macOS 27's.

## What's new since 1.3.0

- **Blocks**: turn on Blocks in the settings window's Plugins page, or with `[plugins.blocks] enabled = true`. Each command and its output is then a block. While you scroll through a long output, the block's prompt and command line stay pinned at the pane's top, and a click on them goes to the prompt. A thin line divides the blocks, and the gutter's bar runs along each one.
- **Select a block**: click it, or press ⌘↑ for the last one, then ↑ and ↓ to move. ⌘C copies its command and output, and Escape ends the selection.
- **A block's menu**: right-click a block and open Block to copy its command, its output or both, to select them, or to see Block Details: its exit status, when it started, how long it ran and its folder. Run Command Again types the command at the prompt and runs it.
- **Smooth scrolling**: set `[window] smooth-scroll = true`, and the text follows your fingers on a trackpad or a Magic Mouse pixel by pixel, at every refresh of the display, and keeps gliding as you lift them. A mouse wheel's step glides, and the scroll bar's knob moves the text by pixels.
- **The status bar has three sides**, start, center and end, each plugin's view at its own width.
- **Controls as macOS 27's**: on-or-off settings are switches, menus of values are pop-up buttons, and the Settings, Keys and Plugins pages show their rows in rounded groups. Shortcuts show as key caps, problems as callouts, and search fields as capsules. Buttons have macOS's sizes, and a dialog's main button is filled with the accent.
- **New plugins in the registry**: `sephiroth74/open-in-editor` opens a pane's scrollback, or a command's output, in your text editor, its long lines whole. `sephiroth74/git-folder` shows the focused pane's folder and its git branch in the status bar. `sephiroth74/snap` 0.3.0 makes an image of a command and its output too. Install them with `sleip add`, or from the settings window's Plugins page.
- **Plugins**: a plugin can stand in for another, such as a tab bar of its own in place of Lokyr's. The plugin API 0.1.6 draws the commands' blocks, selects them, reads the command line and runs a command at the prompt. It also writes temporary files, reads a folder's git branch and a range of rows, and tells the time of day. Plugins can draw macOS 27's controls too.

## Changed

- The pane's context menu is shorter: splitting, moving and closing the pane are in its Pane submenu.
- Buttons, toggles, fields and segmented controls are 24 points high, as macOS's, with rounder corners, and a disabled control dims whole.
- The Settings page's on-or-off keys are switches, and its menus of values are pop-up buttons, which open over the button with the value ticked.

## Fixed

- Show Hints labels the links and paths of a long line of no spaces, such as minified JSON wrapped over more rows than the pane shows.
- A text field that has the keyboard, such as the find bar's, leaves ⌥⌘ and an arrow, and ⇧⌘C, to Lokyr.
- In zsh, with a plugin that switches the history as you type, the command's header no longer shows the right prompt.
- A program that prints the shell's mark of a command's start, such as `cat` of a file that holds one, no longer changes the command's header nor its marks.
- A plugin that starts while the view stays still sees the view at once.
- A Luau plugin that hands back an empty list hands back a list, not an empty map.

## Before you update

- Plugins installed for 1.3.0 keep working: the plugin API is 0.1.6, which takes 0.1.5's plugins.
- Blocks and smooth scrolling are off by default. Blocks take the command header's place while they run: move what you set in `[plugins.command-header]` to `[plugins.blocks]` to keep the header's look.
