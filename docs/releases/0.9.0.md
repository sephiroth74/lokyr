## What's new

- **Plugins from the registry**: `sleip search` lists the plugins on [pkg.lokyr.dev](https://pkg.lokyr.dev), each marked when it needs another version of Lokyr, `sleip info owner/name` tells one, and `sleip add owner/name` installs it, checked against the registry's signed index; `sleip update` takes the new versions. Lokyr loads a plugin as it is installed, without restarting.
- **The first plugins**: `sephiroth74/snap` makes an image of the terminal's text, of the selection or the screen, in a frame as a macOS window's, to copy or to save; `sephiroth74/awake` keeps the Mac awake from a button beside the window's buttons, always or while a tab runs a program; `sephiroth74/font-picker` chooses the terminal's font among the monospaced families, previewed as you move through them.
- **Publishing a plugin**: `sleip publish` proposes a version to the registry, and a guide for plugin authors takes you from `sleip new` to a published plugin; a guide for theme authors tells every color of a theme.
- **Notices as cards**: an error or a warning of Lokyr's comes down from the top right of the window in a card of two lines, whose buttons copy the whole message and close it; a failure goes by itself after a few seconds, unless the pointer rests on it.
- **Quick tips**: once a week at most, as Lokyr starts, a card at the window's bottom right tells a shortcut as your keymap binds it, or a feature that shows in no menu. Don't show again stops them; Help › Show a Tip shows one at once.
- **Install Command Line Tools**: Lokyr › Install Command Line Tools… links `lokyr` and `sleip` into `/usr/local/bin`, so that they run in any terminal.
- **The cursor's length**: `[cursor] length`, from 0.1 to 1, a share of the cell that a bar or an underline cursor takes.

## Fixed

- Lokyr run from its disk image asks to be moved to Applications first, as its updates and its command line tools need.
- A tab shows its program running while any of its panes runs one.
- A plugin whose installed folder moved keeps running.
- A failed `sleip add` or `sleip update` leaves the installed plugins as they were.
- A file that a plugin saves through the save panel is marked as downloaded, as a browser's are, so that macOS checks it before it opens.
- `permissions.toml` that does not read keeps your answers, and its notice shows once.

## Before you update

- Plugins installed for 0.8.0 keep working: the plugin API is 0.1.1, which takes 0.1.0's plugins.
