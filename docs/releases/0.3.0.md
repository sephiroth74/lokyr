## What's new

- **Links under ⌘**: hold Command and move the pointer over a link, a web address, a file or a folder: Lokyr underlines it and shows the pointing hand, and a click opens it.
- **Updates**: Lokyr checks for a newer version once a day at most, and Lokyr › Check for Updates… checks at once. A new version shows in this window, with its notes, to install now or as Lokyr quits. `check = false` under `[updates]` in the config turns the daily check off.
- **The disk image**: Lokyr comes as a disk image, signed and notarized by Apple: drag Lokyr onto Applications to install it.

## Fixed

- A `file:` link without a path no longer ends Lokyr as it opens.
- After output scrolls the window, the context menu's commands act on the text that was clicked, not on what came to its place.
