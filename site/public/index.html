Lokyr

A fast terminal emulator for macOS, written in Rust, where every visible feature is a plugin.

  • macOS 26 or later
  • Apple Silicon
  • MIT, open source
brew install --cask sephiroth74/tap/lokyr

Why Lokyr

A small core, and plugins for everything you see.

  • Plugins all the way

    Tabs, splits, search, themes and the command palette are plugins, on the same API that everyone else gets. The core keeps the terminal itself.

  • Plugins you can trust

    A third-party plugin is a Luau script in a sandbox of its own. It reaches only what it declares, and Sleip, Lokyr’s package manager, shows you that before it installs.

  • Fast where you feel it

    Its own VT core, with 8-byte cells, and a Metal renderer on the GPU: a frame of steady output in about a quarter of a millisecond at 4K.

  • Native on macOS

    An AppKit window, CoreText shaping and font fallback, input methods, Secure Keyboard Entry, and a quick terminal on a global key.

  • Ready for agents

    A tab tells what the AI agent in it, as Claude Code, Codex or Gemini CLI, is doing: at work, waiting for you, or done, with a notification while you look elsewhere. Soon, Lokyr becomes an MCP server.

  • One plain file

    Every setting lives in one TOML file that can sit with your dotfiles, checked before Lokyr applies it.

Get it

Install it, and it keeps itself up to date.

  • 01

    With Homebrew

    The cask installs the app, and links lokyr and sleip into Homebrew’s bin.

    brew install --cask sephiroth74/tap/lokyr
  • 02

    From the disk image

    Download the DMG of the latest release, open it and drag Lokyr into Applications. Lokyr › Install Command Line Tools puts lokyr and sleip on your PATH.

  • 03

    Then, plugins

    Sleip installs plugins from pkg.lokyr.dev, and shows what each one may reach before it does.

    sleip add sephiroth74/snap

macOS 26 or later, on Apple Silicon. The app and its disk image are signed and notarized by Apple; Lokyr takes its updates by itself, through Sparkle, a check a day at most.
