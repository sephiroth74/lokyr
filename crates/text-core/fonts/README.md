# Symbols Nerd Font Mono

`SymbolsNerdFontMono-Regular.ttf` is the font of symbols alone of [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts), release v3.5.1, unchanged: the icons that prompts and tools such as `ls` show, which the terminal draws when the configured font lacks them, as Ghostty, kitty and WezTerm do with the same font. The binary includes it.

- **Source**: [`NerdFontsSymbolsOnly.zip`](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/NerdFontsSymbolsOnly.zip) of the v3.5.1 release, whose SHA-256 is `fdca3682534f6f65e1ccb2345b0362ccf67d9b8eca7c8025330946e93e2473bc`.
- **The font's SHA-256**: `fe471e538392f51910faab985fa8e192a39dd3426125edd15b71b3680df0e749`.
- **License**: the font is under the MIT license, in [LICENSE](LICENSE), as Nerd Fonts gives it. Its icons come of the sets below, each under its own license, as the release's README lists them, whose texts [licenses](licenses) holds: those that Nerd Fonts' repository keeps beside each set's sources at v3.5.1, and, for the sets without one there, Devicons, extraglyphs, Font Awesome Extension, Font Logos, Seti and Power Symbols IEC, their own repository's, of its default branch on 1 November 2026. The texts are as their sources give them, but for their lines' ends, made LF, and a byte-order mark taken off Codicons'.
